## This Repository is for coding work in MB5370 Techniques in Marine Science Module 1.

- Code covers Basic R syntax, basic plotting, setting up Version control with Github, setting up and using AI assistants like Chattr & Gitcopilot, as well as basic functions and data looping. 
- Default datasets are used for learning purposes as well as the Palmer Penguins data set to explore morphological varriation across different islands.
